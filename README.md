## Featured Projects｜代表项目

### UAV Synthetic Data and Landing Perception
**无人机合成数据与降落感知系统**

An AirSim-based workflow for UAV visual data collection, automatic YOLO annotation, model training, and robustness evaluation.

基于 AirSim 构建无人机视觉数据采集、自动标注、模型训练及鲁棒性评估流程。

- Synchronized multi-scene RGB and semantic image collection  
  多场景 RGB 与语义分割图像同步采集
- Automatic semantic-mask-to-YOLO annotation  
  语义分割图到 YOLO 标签的自动转换
- Clear and motion-blur paired experiments  
  清晰与运动模糊配对实验
- Scene-specific model evaluation and closed-loop data iteration  
  分场景模型评估与闭环数据迭代

`Python` `AirSim` `OpenCV` `PyTorch` `YOLO`

> 🚧 A public, reproducible version of this project is being prepared.  
> 项目的可复现公开版本正在整理中。
